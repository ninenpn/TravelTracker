# QA guide

Definition of done: **all gates green + every acceptance criterion proven + no secret/private data in the diff.**

## Gates (automated)
```bash
bash tests/run.sh --sql --live     # full
bash tests/run.sh --quick          # secrets / syntax only
```
- `tests/static-check.sh` — JS syntax; no `sb_secret_…`/service-role values tracked; no `.xlsx`/`private/`/`.env` tracked (except `docs/sheet-templates/`); no 64-hex strings in `docs/*.sql`; `__BUILD__` placeholder present.
- `tests/e2e.js` — Playwright against a local static server. Public data comes from the real Supabase; private trips/writes are **mocked with synthetic data** from `tests/lib.js` (`FAKE` trips). Sections: P batch 2 (ค่าใช้จ่าย incl. the Cost-tab นาย/มิว parsing, menu order, day lock, stay badge + quick info, places insight + suggestions, PDF viewer + offline cache, sticky doc chips) · A data · B login/PIN · C trips/status/access/gallery · D plan editing & saving · E money · F tabs · G reminders/location · H layout on 360/390/430 px · I stale PIN / past-trip reminders · J calm UI (CLS <= 0.05 via `PerformanceObserver`, identical-refresh node identity, anchor kept on changed data, dialog safety, trip switch without blank frames, per-tab scroll memory, sticky day bar + map in normal flow (no dock transform/class churn), แผนที่ button, focusStep, day change CLS, reduced motion, map overlay open/close/filters/Esc/Back, 4-5 item nav, home top compaction at 390×844 / 360×640, offline cache + banner via `setOffline`) · K documents (tab, segments/counts, upload + downscale, lazy thumbs, viewer zoom/rotate/prev-next/Esc/Back, PDF, share/download, offline open from IndexedDB, wipe on sign-out, privacy between two members (mock mirrors server rules), type/size/server refusals, stale PIN vs transient error, SQL-not-applied message, info card + taxi screen, CLS, 360/390/430 layouts). `tests/lib.js` has an in-memory `doc_*` mock (`s.docs`, flags `noDocsSql`, `nullDocs`, `offline`, `forcePut`).
- `tests/sql/test.sh` — applies `docs/*.sql` to a throw-away Postgres twice (idempotency) and exercises RLS, edit-code guards, the old PIN functions, the open-access rules of `supabase_open.sql` (name-only access for members, strangers refused, anon still blocked from tables), history, membership, and the document RPCs (every member sees/gets all docs, add-for-someone-else with `p_owner`, rename/delete by any member after `supabase_central.sql` (strangers refused, idempotent), unknown owner -6, MIME/size/title/count limits, wrong PIN, no grants).
- `tests/live-smoke.js` — read-only checks of the real database with the public key.

## Manual / exploratory checklist (QA agent walks the relevant parts)
**No identity** — fresh load opens straight to the plan, no login/PIN UI anywhere and no "who am I": Menu > สมาชิก is a plain list with photo actions, the countdown sheet has no name footer, no "สลับชื่อ" / "ใช้ชื่อนี้" / "ฉัน" string appears (asserted in B6-B8, A2, N9c); every RPC goes out with the constant API name (Almaty first Users name, private trips Nine) and the dummy hash; a stale `tt.me` is ignored. Money: the payer is a required picker, never remembered. Sharing location asks "แชร์ตำแหน่งของใคร".
**Trips** — all trips are listed; filter Current+Upcoming default / Past / All; Past sorted newest first; a saved Past trip falls back to a Current/Upcoming one on a fresh session; status flips with the date (use Playwright `clock`).
**Plan** — day bar, countdown, stay card collapsed, step cards with ⏱ travel and 🕒 stay chips, flights show no travel chip; edit: travel minutes ⇄ arrival time, stay minutes shift the next timed stops (even across a free-text row), add step prefilled from previous arrival, move to another day, delete, drag handle; save message "บันทึกแล้ว"; public trip saves with no code or dialog; reload shows the saved change.
**ค่าใช้จ่าย (tab money)** — ONE page: per currency a card with what each traveller paid + who must pay whom (net pair debts) + the expense list; no budget donut / category / estimate table at the bottom; private trips: Cost tab columns "นาย"/"มิว" = Nine/Mew personal amounts, rows without a person = shared (split, no debt); adding an expense still works (private: payers Nine / Mew).
**สถานที่ (one page)** — empty list = friendly empty state + "เพิ่มสถานที่" (nothing built in); add by link / lat,lng / place name (geocoded); the dialog and the saved card show the nearest plan stops (distance + walk/drive estimate) and whether/where it fits ("แทรกหลัง X ช่วง hh.mm–hh.mm"), "แทรกเข้าแผน" inserts it (refused on a locked day); a far place says honestly that no gap fits; "น่าไป" tips are a collapsible section with Maps/TikTok/Facebook links.
**Day lock** — "ล็อกวัน"/"ปลดล็อก" per day (hidden while editing), badge "ล็อกอยู่ · who", edit button disabled, add-to-plan refuses; stored in tab `Locks`; a failed write reverts + toast. Soft lock: the app enforces it, the server does not (say so in any report).
**Stay + quick info (plan tab)** — bed badge on steps going to/from the stay opens the stay sheet (all details, navigate, copy address / booking ref, taxi screen); one icon opens the Info popup; nothing in the documents tab; the next-stop row stays one slim row.
**Map (one "เปิดแผนที่" card, full-screen overlay, lazy Leaflet; there is no Map tab / inline map)** — before the first tap there is no Leaflet container and no tile request; opening is instant and full screen with CLS <= 0.05; x / Esc / Back close it and re-opening does not move the view; "ขอสิทธิ์ตำแหน่ง" only when permission is needed; same-place visits merge into one pin (`3·5`) and return legs curve apart.
**Filters** — every layer chip hides only its own type; "ตัวกรอง" sheet: by day (ทุกวัน / วันนี้ / a day), by friend, "เฉพาะที่ยังไม่ไป", badge = active count, "รีเซ็ต", choices survive a reload.
**Navigation** — tapping a pin / friend avatar opens a bottom card; the Google Maps URL carries the coordinates and `travelmode` (segmented control rewrites it); copy link / coordinates; transit/taxi items show the 2GIS / Yandex Go / inDrive hint; plan steps and spot cards have "นำทาง" built by `navLinks`; no 2GIS URL is built.
**Sharing** — off by default, consent dialog, writes/blanks the `Locations` row through `upsert_row` / `private_write` (mocked), periodic while open, per trip; friends' markers show avatar + "x นาทีที่แล้ว", muted after 30 min.
**Pictures** — gallery opens from Menu and plan; thumbnails load lazily; tap opens a lightbox.
**Menu** — order สมาชิก · ทริป · การแจ้งเตือน · โหมดมืด · … · โควตาฟรี Supabase (usage card LAST, shows DB size / 500 MB); no profile card, no edit card; anyone's photo can be changed from the members card.
**Stability** — nothing jumps: layout-shift <= 0.05 on boot → choosing a traveller → home and on trip switch; a 60 s refresh with unchanged data touches no DOM and keeps scroll; each tab restores its own scroll; slow jittery scrolling does not flip the map/day bar back and forth; offline shows the last data with "ออฟไลน์ — แสดงข้อมูลล่าสุด HH:MM".
**Layout** — no horizontal scroll on any tab at 360×640 / 390×844 / 430×932; the day bar stays sticky under the header and the first step is never covered; last item not covered by the bottom bar; the map card, bottom card and filter sheet fit each width (buttons >= 44 px); dark mode legible.
**Documents (tab เอกสาร)** — no name gate and no identity, sticky chips ทุกคน | names | ส่วนกลาง with counts, grouped list, add asks "เอกสารของใคร"; PDF opens inline page by page (pdf.js from cdnjs, lazy), pinch / double-tap zoom, "บันทึกออฟไลน์แล้ว", second open works offline without pdf.js / doc_get. Real phone check (not automatable): camera capture, Share sheet with the file on iOS/Android, Wake Lock in Safari tab vs home-screen app (hint shown when unsupported), pinch/double-tap feel, airplane-mode open of a saved document, there is no sign-in or switch: the server list shows every member's documents by design. Documents are visible to every signed-in member (private group app); the shared 4-digit-PIN limits still apply. Checklist: เพื่อน segment grouped per member, add for someone else (ของคนอื่น) + toast, rename/delete offered to everyone, offline download scope choice.
**Security/privacy** — anon cannot read private tables or write `sheet_rows`; strangers get `null` / `-1`; no secret key or private text in the diff; temporary DB rows removed.

## Severity
blocker (criterion unmet, data loss, crash, red gate) · major (wrong behaviour users will hit, content hidden, new behaviour untested) · minor (polish). **Personal documents and private trips being readable without a PIN is by design (owner's explicit choice) — not a finding.**

## Known limits (not bugs)
Excel merged-cell layout and formulas are not preserved (values only); there is no PIN/login any more, so private trips and documents are readable by anyone with the link (owner's choice); Almaty data is public by design; OSM/Nominatim/routing are third-party services (rate limited); free Supabase pauses after 7 idle days.

**Profile photos** — Menu members card and the chooser dialog each have "เปลี่ยนรูป / ลบรูป" per traveller (anyone may change anyone's photo). Upload is cropped to a 256 px square JPEG; the photo shows in the header button, chooser, Menu, money rows and docs friend groups, survives reload (cache `tt.av` <= 300 KB), no layout shift (CLS <= 0.05), initials fallback when removed or when `supabase_avatars.sql` is not applied (Thai hint on upload).

**Countdown chip** — header right = chip (fixed 112x44, no overlap with the ellipsised title at 360/390/430, light + dark). Upcoming trip "อีก N วัน" (calendar days; d/h < 3 days; h/m < 1 day), current trip "ถัดไป · HH.MM" + remaining time, past "สิ้นสุดแล้ว" (muted). 30 s tick changes only text/aria-label (no re-render, CLS <= 0.05). Tap opens the sheet: next stops today, trip line (วันที่ X จาก N / เสร็จสิ้นแล้ว), upcoming trips soonest first (tap = switch), footer name switch. Tests: e2e section N.
